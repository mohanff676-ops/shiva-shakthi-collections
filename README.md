# \# 💎 Shiva Shakthi Collections

# 

# A modern jewellery e-commerce website built to deliver a smooth online shopping experience with product browsing, customer accounts, cart management, and an administration dashboard.

# 

# 🌐 \*\*Live Website:\*\* https://shiva-shakthi-collections.vercel.app

# 

# \## 🚀 Features

# 

# \- Product catalogue and product details

# \- Product search, filtering and sorting

# \- Shopping cart and wishlist

# \- User registration and authentication

# \- Customer account management

# \- Admin dashboard

# \- Product and order management

# \- WhatsApp order integration

# \- Responsive user interface

# \- Supabase database integration

# 

# \## 🛠️ Tech Stack

# 

# | Technology | Purpose |

# |---|---|

# | React | Frontend |

# | TypeScript | Programming language |

# | Vite | Build tool |

# | Tailwind CSS | Styling |

# | Supabase | Backend and database |

# | Vercel | Deployment |

# | Git \& GitHub | Version control |

# 

# \## 💻 Run Locally

# 

# \### 1. Clone the repository

# 

# ```bash

# git clone https://github.com/mohanff676-ops/shiva-shakthi-collections.git

# ```

# 

# \### 2. Open the project

# 

# ```bash

# cd shiva-shakthi-collections

# ```

# 

# \### 3. Install dependencies

# 

# ```bash

# npm install

# ```

# 

# \### 4. Configure environment variables

# 

# Create a `.env` file using `.env.example` as a reference.

# 

# Configure:

# 

# \- `VITE\_SUPABASE\_URL`

# \- `VITE\_SUPABASE\_ANON\_KEY`

# \- `VITE\_WHATSAPP\_NUMBER`

# \- `VITE\_SITE\_URL`

# 

# Never commit real credentials or service-role keys.

# 

# \### 5. Start development server

# 

# ```bash

# npm run dev

# ```

# 

# \## 📦 Production Build

# 

# ```bash

# npm run build

# ```

#
